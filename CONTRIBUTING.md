# Contributing

Read `docs/DEVELOPER_HANDBOOK.md` and `docs/RESEARCH_HANDOFF.md` before changing
model semantics. Include a problem statement, assumptions, evidence, validation
and limitations with substantive numerical contributions. Keep public inputs
independent of confidential facility data and preserve required attribution.

Run formatting and `scripts/run_verification.py`; use actual integration checks
when changing an external adapter. Record any data/model protocol deviation.
Do not commit environments, raw/participant data, downloaded external source,
credentials, local caches or built distribution files. Reacquisition instructions
and aggregate audited results belong in the source tree.

Original contributions are offered under the project's MIT license. Contributors
must have authority to contribute their work. Third-party assets retain their
own terms and require a separate review before inclusion.
