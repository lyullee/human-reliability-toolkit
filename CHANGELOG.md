# Changelog

## 0.3.0 — 2026-10-26

- Added executable unit-checked actions, physically supported error variants,
  permissives and typed same-population causal/barrier graphs.
- Added serializable risk cases, evidence checks, conditional scenario ledgers,
  versioned consequence providers and actual DynaSense/PRISM risk-path checks.
- Added message/readback, handover and individual work-control state models;
  operational opportunity/recovery ledgers and reviewed annual demand exposure.
- Added intervention comparisons with preserved baselines and explicit assumed
  overrides, paired uncertainty samples and static FV/RAW/RRW importance.
- Added optional SimPy process feedback, role-visible policy inputs, remaining-work
  preemption and explicit bounded repeat/observed retry policies.
- Added finite progress checking, serial integer-grid deadlines, task-net
  compilation, cue visibility, diagnostic beliefs and bounded monitoring.
- Added finite-hyperprior partial pooling, held-out/predictive scores, quantified
  elicitation, procedure conformance and serializable assurance lifecycle review.
- Added source-linked numerical workflows, conditional parameter schemas,
  operational templates, English manuals and requirement-to-test acceptance records.
- Preserved the seven-source numeric catalog; added a separate user-catalog type
  for reported observational probabilities without invented denominators.

## 0.2.0 — 2026-10-26

- Added a source-qualified 1,334-record numeric catalog from seven selected
  sources: 578 observed simulator/context count records and 756 method records
  with explicit kinds, provenance, applicability and reuse conditions.
- Added offline Python/CLI queries, source codebook interpretation, explicit
  application reviews, prior-based count binding and evidence-linked annual
  conversion with target exposure. Incomplete coefficients cannot be used as HEPs.
- Added configurable SPAR-H and HEART reference profiles and the limited
  IDHEAS-ECA function kernel, with placeholder and source-anomaly safeguards.
- Added checksum-pinned source reacquisition, independent numeric curation,
  candidate review, mixed-data notices and an evidence-to-risk example.
- Rewrote the README and added detailed English user and human-evidence guides.
  Extended verification to catalog behavior, documentation and core-wheel loading;
  packaged JSON and primary documentation now participate in the release gate.

## 0.1.0 — 2026-10-26

- Added typed task, context, human failure event, evidence and estimate contracts.
- Added qualitative, probability, dependency, recovery, timing, workflow and
  resource models with configurable parameters and estimator registration.
- Added FTA/BDD, ETA, Bayesian networks, LOPA screening, risk registers,
  uncertainty, sensitivity, process alarm context and optional CoolProp.
- Added eight existing-project integration boundaries and reproducible checks.
- Cataloged 15 public dataset families and acquired/audited nine selected families.
- Recorded participant-held-out experiments and withheld questionable flag data.
- Added manuals, architecture, source/use policies, development history,
  research handoff, repeatable verification and source distribution inspection.
